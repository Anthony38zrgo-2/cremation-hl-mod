Scientist assets included in the Cremation Mansion rescue event.

- `hfd_scientists.zip`: Valve HD and Blue Shift HD scientist models and their sequence/model companions. Only scientist assets were imported; unrelated zombie models from the archive were excluded.
- `f_scientist_low_for_hl1_v2.rar`: female Valve and Gearbox scientist models. The accompanying credits file is preserved as `female-scientist-credits.txt`.

The event randomly selects one of four compatible scientist model families and a random skin. The copied models are stored under `models/cremation/scientists/`.
