# trigger_safe_fall

When player is currently not on the ground and touches this entity, the next fall won't deal damage to the player.

The design is similar to the entity of the same name from Quake II PSX project.

{{% hint info %}}
The player still plays a fall pain sound if the fall velocity was enough to deal damage normally.
{{% /hint %}}
