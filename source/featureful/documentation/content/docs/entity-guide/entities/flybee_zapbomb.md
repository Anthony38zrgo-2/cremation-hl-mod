# flybee_zapbomb

The zap bomb created by the [flybee's]({{< ref monster_flybee >}}) beam attack.

This makes an animated sprite that explodes in 0.5 seconds, dealing radius damage and producing a visual shockwave. After that the sprite expands and fades away.

### Skill variables

* **sk_flybee_dmg_beam** - zap explosion damage.

### Soundscripts

* **Flybee.Zap** - zap explosion sound.

### Visuals

* **Flybee.Zap** - zap attack sprite.
* **Flybee.ZapWave** - beam settings for the shockwave.
