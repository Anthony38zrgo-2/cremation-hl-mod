# func_rotating

[TWHL](https://twhl.info/wiki/page/func_rotating)

### New parameters

* ![](/images/svencoop.png) `Obey Trigger Mode` - make `func_rotating` interpret the use-type when triggered (`On` is to spin up and rotate, `Off` is to spin down and stop). By default in Half-Life `func_rotating` ignores the input use-type.
